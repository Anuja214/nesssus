EXPERIMENT 1: VULNERABILITY SCANNING USING NESSUS

AIM:
To perform vulnerability scanning using Nessus for OWASP Juice Shop.

PROCEDURE:

1. Download and install Node.js from:
   https://nodejs.org

2. Download and install Git from:
   https://git-scm.com

3. Verify installation:
   node -v
   npm -v
   git --version

4. Download OWASP Juice Shop:
   git clone https://github.com/juice-shop/juice-shop.git --depth 1

5. Open the project folder:
   cd juice-shop

6. Install dependencies:
   npm install

7. Start the application:
   npm start

8. Open the application in browser:
   http://localhost:3000

9. Open Nessus:
   https://localhost:8834

10. Login to Nessus.

11. Click My Scans -> New Scan -> Basic Network Scan.

12. Configure scan:
    Name: OWASP Juice Shop Scan
    Target: 127.0.0.1

13. Configure TCP port 3000 in port scanning settings.

14. Click Save and Launch.

15. After completion, open Vulnerabilities and observe the results.

IMPORTANT FINDING:

Vulnerability Name: As detected by Nessus.
Severity: As detected by Nessus.
Description: Security weakness identified during scanning.
Recommendation: Apply the recommended security updates and configurations.

CONCLUSION:
Successfully performed vulnerability scanning using Nessus and analyzed the scan results.

EXPERIMENT 1: VULNERABILITY SCANNING USING NESSUS

AIM:
To perform vulnerability scanning using Nessus on OWASP Juice Shop.

REQUIREMENTS:
1. Docker Desktop
2. Nessus
3. OWASP Juice Shop

PROCEDURE:

STEP 1: Install Docker
1. Download Docker Desktop from:
   https://www.docker.com/products/docker-desktop/
2. Install Docker Desktop.
3. Start Docker Desktop and wait until it is running.

STEP 2: Verify Docker

Open CMD and execute:

docker --version

docker ps

STEP 3: Download OWASP Juice Shop

docker pull bkimminich/juice-shop

STEP 4: Run OWASP Juice Shop

docker run -d --name juice-shop -p 3000:3000 bkimminich/juice-shop

STEP 5: Verify Container

docker ps

Check whether juice-shop is running.

STEP 6: Open Juice Shop

Open Chrome and enter:

http://localhost:3000

STEP 7: Open Nessus

Open Chrome and enter:

https://localhost:8834

Login to Nessus.

STEP 8: Create New Scan

1. Click My Scans.
2. Click New Scan.
3. Select Basic Network Scan.

STEP 9: Configure Scan

Name: OWASP Juice Shop Scan

Description: Vulnerability scanning using Nessus.

Target: 127.0.0.1

STEP 10: Configure Port

1. Open Discovery settings.
2. Configure TCP port 3000 to be included in the port scan.
3. Keep other settings at safe defaults.

STEP 11: Launch Scan

1. Click Save.
2. Open the saved scan.
3. Click Launch.
4. Wait for the scan to complete.

STEP 12: View Results

1. Open the completed scan.
2. Click Vulnerabilities.
3. Observe the severity levels.
4. Note the vulnerability name, description and solution.

IMPORTANT FINDING:

Vulnerability Name: As detected by Nessus.

Severity: As detected by Nessus.

Description: Security weakness identified during scanning.

Recommendation: Apply the recommended security updates and configurations.

CONCLUSION:

Successfully deployed OWASP Juice Shop using Docker and performed vulnerability scanning using Nessus.
